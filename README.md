# SealDice2MC

Sealdice2MC is a server-side mod that supports the Sealdice (a TRPG dice bot) Minecraft adapter. It connects your Sealdice bot directly to your Fabric or (Neo)Forge server.

## Features

- **Bot Adapter:** The mod opens a port on your server for the Sealdice bot to connect to.
- **Port Configuration:** You can easily change the connection port using the `/sealport <port>` command. This command requires OP permissions and can also be executed from the server console.
- **In-game Interaction:** Allows players to send messages and roll commands to the Sealdice bot directly from the game using commands (like `/sealdice <text>`) or public chat.
- **Server-Side Only:** You only need to put the downloaded `.jar` file into your server's `mods` folder. Players can join your server with a vanilla Minecraft client.
