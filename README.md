# SealDice2MC

SealDice2MC是一个服务器端模组，支持将Sealdice（一个TRPG骰子机器人）连接到Minecraft服务器，支持fabric和（Neo）Forge服务器，允许玩家直接从游戏中与Sealdice机器人进行交互，发送消息和掷骰命令。

## 说明

- 该模组在服务端开放一个端口，供Sealdice机器人连接。
- 连接端口可以通过`/sealport <port>`命令轻松更改。该命令需要OP权限，也可以从服务器控制台执行。
- 允许玩家直接从游戏中使用命令（如`/sealdice <text>`）或公共聊天向Sealdice机器人发送消息和掷骰命令。
- 该模组仅需将下载的`.jar`文件放入服务器的`mods`文件夹中即可。玩家可以使用原版Minecraft客户端加入您的服务器。
